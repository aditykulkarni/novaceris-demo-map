How your edits are kept

  1. While you type, edits are kept in this browser only. Show in the map opens the map with them; nobody else sees them yet.
  2. To keep them with the demo, click Save file. It downloads demo-config.json. On the laptop, put it in the demo folder next to index.html, replacing the old one. For the web site, upload it to the repository (GitHub, Add file, Upload); the site updates within a few minutes.
  3. Then click Discard edits, so this browser shows the demo as saved.

Tab links are never put in the file. The web site is public, so links to the tenant stay in this browser. Use Copy links and Paste links to move them to another laptop.
